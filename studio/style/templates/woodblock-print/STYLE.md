## The look
An animated Japanese woodblock print, built entirely in code and never
pretending to be 3D. Draw the artwork as flat 2D shapes on {{print.plates}}
separate printing plates — a light colour block, a deep colour block and a
black key-line block — inked only in {{palette}}. {{palette.accent.name}}
({{palette.accent}}) is used once: {{palette.accent.role}}.

## How it is built
Print the plates with one shader: {{print.misregistration}} of misregistration
between plates, wood grain inside the flat colours ({{print.grain}}), paper
fibre in {{palette.paper.name}} ({{palette.paper}}), uneven ink. Deckled sheet
with a border: {{print.border}}. Stylise {{motion.elements}}. Every frame is a
pure function of the frame number.

## How it moves
Animate on {{motion.timing}}, like a print coming to life. One clear event and
a final image that lands. Text on screen: {{motion.text}}.

## Never
